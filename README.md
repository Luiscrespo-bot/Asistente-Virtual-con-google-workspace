## 📝 Descripción

Este proyecto es un asistente virtual diseñado para trabajar con Google Workspace, proporcionando funcionalidades que agilizan procesos comunes y mejoran la productividad.

### 🤖 IA en el Desarrollo

**Importante:** Este proyecto fue inicialmente creado con la asistencia de **Inteligencia Artificial (IA)** como herramienta para acelerar el desarrollo y crear un prototipo funcional rápidamente. Sin embargo, nuestro objetivo es:

- **Eliminar gradualmente la dependencia de IA** en el código
- **Reemplazar la IA con Inteligencia Orgánica (IO)** - soluciones creativas y personalizadas del equipo
- **Priorizar la Inteligencia Humana (IH)** - decisiones, revisiones y mejoras implementadas por desarrolladores con experiencia
- **Mantener la calidad y las mejores prácticas** a través de contribuciones humanas conscientes

Este es un compromiso con un desarrollo más consciente, donde la tecnología sirve como punto de partida, pero la excelencia viene del pensamiento humano crítico.

## 🚀 Instalación

### Requisitos Previos

- Node.js v16+
- npm o yarn
- Cuenta de Google Workspace

### Pasos

1. Clona el repositorio:

```bash
git clone https://github.com/Luiscrespo-bot/Asistente-Virtual-con-google-workspace.git
cd Asistente-Virtual-con-google-workspace
```

2. Instala las dependencias:

```bash
npm install
```

3. Configura las variables de entorno:

```bash
cp .env.example .env
# Completa tu archivo .env con tus credenciales
```

4. Compila el proyecto:

```bash
npm run build
```

## 📖 Uso

### Inicio Rápido

```bash
npm start
```

### Desarrollo

```bash
npm run dev
```
